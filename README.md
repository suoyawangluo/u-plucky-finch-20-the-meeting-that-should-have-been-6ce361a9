One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny — a [make.fun](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) bounty entry.

## The entry

> I joined the meeting from my inbox, so I could read the email while we discussed the email.

## How it runs

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies the gate: 1–200 characters, a single line, non-blank. The output is deterministic — every run writes the same bytes.
